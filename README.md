# The Mini Arcade

A free, browser-based five-game arcade built with plain HTML, CSS, and JavaScript.

## Games
- Flappy Bird: pass 10 pipes.
- Pixel Platformer: collect five coins and reach the flag.
- Breakout: clear the bricks with three lives.
- Space Invaders: destroy 15 aliens.
- Snake: collect 10 snacks.

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `mini-arcade`.
2. Upload `index.html` to the repository's top level (root).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show the website URL in the Pages section, usually:
   `https://YOUR-USERNAME.github.io/mini-arcade/`
7. Send that URL in your email.

## Notes
- The site uses browser local storage for the visitor's personal best and local arcade score.
- Scores are local to each person's browser; they are not shared on a global leaderboard.
- This project does not collect names, email addresses, or other personal information.
